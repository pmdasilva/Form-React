# 📋 Demanda Real: Sistema de Cupons de Desconto

Contexto

#### Você trabalha em um e-commerce.
O time de produto solicitou uma funcionalidade para aplicar cupons de desconto durante o checkout.

# Regras

1. O valor do pedido deve ser maior que R$ 0.
2. Cupom PROMO10 concede 10% de desconto.
3. Cupom PROMO20 concede 20% de desconto.
4. O desconto máximo permitido é R$ 100.
5. Cupons inválidos devem lançar erro.
6. valor final nunca pode ser negativo.
7. sistema deve retornar:
    - valor original
    - valor desconto
    - valor final
